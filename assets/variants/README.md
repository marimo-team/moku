# Logo variants

All 64 original icon studies, including 41 four-circle variations. [Open the visual index](index.html) to browse by four-circle designs, favorites, or all studies.

The eight favorites (01, 37, 39, 44, 46, 52, 53, 56) were recovered byte-for-byte from the pre-cleanup jj snapshot. Each retains its six original SVGs: icon and outlined Comic Code wordmark, each in adaptive, light-background, and dark-background versions.

The other 56 icon studies were regenerated from the recovered sketchbook code with its original defaults (seed 12; wobble, stroke, and spacing 1). Their `icon.svg` files adapt to light/dark color schemes. Backgrounds are transparent.

**53 · Four personalities remains the selected logo.** The canonical files are still in the parent `assets/` directory; this archive does not change the README logo.
